# Sistema de Gestão Escolar

Projeto desenvolvido em Java para praticar conceitos de Programação Orientada a Objetos (POO).

## Sobre o projeto

O Sistema de Gestão Escolar tem como objetivo organizar informações relacionadas ao ambiente escolar, aplicando conceitos fundamentais da programação orientada a objetos.

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)
- IntelliJ IDEA

## Conceitos praticados

- Classes e objetos
- Herança
- Encapsulamento
- Enumerações (`enum`)
- Tratamento de exceções

## Estrutura do projeto

O código-fonte está organizado na pasta `src`.
